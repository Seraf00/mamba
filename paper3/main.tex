\title{What actually moves boundary error in echocardiographic segmentation?\\
A reproducibility study of real-time instance segmentation on CAMUS}

\begin{abstract}
Deep segmentation networks report mean Dice above $0.90$ on the CAMUS
echocardiography benchmark, at or beyond the level at which two cardiologists
agree with one another. We ask what, if anything, still improves boundary
accuracy in that regime, using real-time instance segmentation as the test bed.

Applying a detector to CAMUS first requires resolving a representational
obstacle: the myocardium is an annulus, and an instance mask is supervised as a
single closed polygon, which has no hole. We encode the epicardium as a filled
contour and recover the myocardium by subtraction, and quantify what any such
encoding can express as an explicit \emph{ceiling} --- a perfect model under it
attains $0.997$ Dice at $0.308$\,mm HD95, exactly one pixel.

We then run thirteen factors over roughly fifty training runs on a single
consumer GPU: encoding, vertex budget, model scale and generation, input
resolution, mask-prototype resolution, augmentation, pretraining, training-set
size, a boundary-weighted loss, the loss gains, and the optimiser. Critically,
we first measure run-to-run variance. Three seeds of one configuration span
$0.134$\,mm HD95, and a paired Wilcoxon test over the 200-frame test set calls
that difference significant ($p{=}0.035$). Read against that floor,
\emph{no factor improves on a stock configuration}. What does register is
training-side: removing augmentation costs $0.318$\,mm, and COCO initialisation
is worth $0.183$\,mm.

Averaged over three seeds the resulting model reaches $3.809$\,mm HD95 at
$2.7$\,M parameters --- the best in the benchmark, ahead of the strongest
baseline by $0.271$\,mm, twice the measured seed floor --- with mean Dice
$0.9113$, which is statistically indistinguishable from the four leading
baselines. It is near-invariant to input resolution where encoder--decoders
scale $4$--$8\times$ with pixel count.

Three findings generalise beyond this architecture. Overlap has saturated on
CAMUS, so boundary distance in millimetres is what discriminates methods.
Single-seed ablations on this benchmark produce false positives. And the
reference implementation for CAMUS ejection fraction selects a contour by
position rather than area, which is harmless on ground truth but drives EF
correlation from $r{=}0.911$ to $r{=}0.030$ on model predictions. All code, the
machine-readable experiment plan and every run artefact are released.
\end{abstract}

\section*{Relationship to other work by the authors}
A preliminary version of this study appeared as a four-page conference
submission, which reported the encoding ceiling, the seed noise floor and a
subset of the ablation grid. The present paper adds the native-resolution
latency protocol, the ejection-fraction analysis against a ground-truth oracle,
the connected-component fault in the reference Simpson implementation, the full
thirteen-factor grid, and per-patient rather than per-frame significance
testing. Results common to both are reported identically.
